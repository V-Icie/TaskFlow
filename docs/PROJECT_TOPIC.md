# Тема семестрового проєкту

**TaskFlow — система керування особистими завданнями.**

Мета: дати користувачеві простий інтерфейс для перегляду та подальшого керування власними завданнями. У практичній №1 реалізовано тільки відображення тестових записів із бази через API. Редагування, створення і видалення будуть додані у наступних практичних.

**Первинні сутності:** Item (у базовому API), надалі Task, User і Category за потреби. Архітектуру й формальну модель домену задокументуємо у практичних №2 та №3.

**Обрана база для початку:** SQLite. У практичній №6 можна буде перейти на PostgreSQL для Docker Compose.
