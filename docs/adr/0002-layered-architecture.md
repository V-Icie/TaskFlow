# ADR 0002: Шари та залежності

- **Дата:** 2026-11-23
- **Статус:** Прийнято

## Ролі

- `src/api/`: HTTP-маршрути, статуси, перетворення вхідних параметрів, JSON-відповіді.
- `src/service/`: сценарії CRUD, перевірка вводу, бізнес-правила, єдині API-помилки.
- `domain/`: сутності `Task`, `User`, `Category`, інваріанти, без HTTP чи SQL.
- `src/tasksRepository.js`: зберігання `tasks` у SQLite.
- `src/db.js`: ініціалізація SQLite та збережений `items` з №1.

## Напрямки

`api → service → repository → database`; service може використовувати domain.

**Заборони:** HTTP-маршрути не виконують SQL напряму; домен не імпортує Express, SQLite чи роутери; service не залежить від HTTP-відповідей; бізнес-правила не ховаються в UI.

`src/app.js` є композиційною точкою збирання залежностей і місцем глобального error handler.
