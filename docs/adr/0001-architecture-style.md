# ADR 0001: Архітектурний стиль

- **Дата:** 2026-11-23
- **Статус:** Прийнято
- **Контекст:** TaskFlow — сольний навчальний проєкт з невеликим API, SQLite та статичним фронтендом; поступово розвивається протягом семестру.
- **Рішення:** Модульний моноліт. Один Node.js процес, розподіл на api, service, domain, repository.
- **Альтернатива:** Мікросервіси (різні процеси, окремі деплої).
- **Чому не мікросервіси:** Вимагають зайвих мережевих контрактів, розгортання, спостережуваності для кількох сервісів, що не відповідає поточному масштабу.
- **Наслідки:** Простий запуск і тестування, один реліз, чіткі модульні межі; масштабування модулів незалежно обмежене.
- **Критерії перегляду:** Незалежні команди, різні потреби масштабування чи окремі цикли релізу модулів.
