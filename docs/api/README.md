# Перевірка OpenAPI у Swagger Editor

1. Відкрийте https://editor.swagger.io/ у браузері.
2. Замініть текст ліворуч вмістом `docs/api/openapi.yaml`.
3. Перевірте, що редактор відображає `/tasks`, `/tasks/{id}` та `/health`, а валідаційних помилок немає.
4. Зробіть **справжній** скриншот редактора та збережіть як `docs/api/swagger_screenshot.png`.
5. Додайте скриншот до репозиторію перед захистом.

**Статус:** локально перевірено YAML-синтаксис та структуру; валідацію в інтерфейсі Swagger і скриншот слід виконати вручну. У застосунок Swagger UI не вбудований згідно методички.


### Зміни практичної №5

У `openapi.yaml` додано заголовок `Idempotency-Key` для `POST /tasks`, кореляційний `X-Request-Id`, HTTP 409/429/503, `Retry-After` та поле `requestId` у моделі помилки. Оскільки файл оновився, скриншот Swagger із попередньої практичної потрібно **перевірити / оновити вручну** після відкриття YAML в https://editor.swagger.io/.
