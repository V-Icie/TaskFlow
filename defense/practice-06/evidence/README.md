# Evidence / Докази реального запуску

Збережи сюди зроблені на своєму Windows-комп'ютері скриншоти:

- `hello-world.png` — результат `docker run hello-world`.
- `docker-ps.png` — три активні сервіси після `docker compose up -d --build`.
- `taskflow-browser.png` — сторінка з отриманими даними та CRUD.
- `api-health.png` — відповідь GET /health або /items.
- `postgres-query.png` — запит до таблиці tasks через psql.

Цей каталог навмисно не містить штучних знімків. Скриншоти треба зробити після реального запуску Docker Compose.
