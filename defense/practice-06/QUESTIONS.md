# Можливі запитання викладача — №6

1. **Що таке Docker?** Інструмент запуску програм у контейнерах зі стандартизованими залежностями.
2. **Чим образ відрізняється від контейнера?** Образ — шаблон, контейнер — запущений екземпляр образу.
3. **Для чого Dockerfile?** Покроково описує збірку образу.
4. **Навіщо .dockerignore?** Скорочує контекст збірки, виключає зайві файли та секрети.
5. **Навіщо Docker Compose?** Одним описом визначає мережу, запуск і залежності кількох сервісів.
6. **Чому PostgreSQL замість SQLite в Compose?** Методичка для рівня 90–100 вимагає `frontend + api + db (Postgres)`; SQLite лишився для локальних практичних №1–5.
7. **Як Nginx звертається до API?** За ім'ям сервісу `api:8080` через мережу Compose; у браузері запити йдуть з одного origin.
8. **Навіщо healthcheck?** Щоб перевіряти готовність PostgreSQL і API та запускати залежні сервіси після них.
9. **Чи зникнуть дані після `docker compose down`?** Ні, якщо не використовувати `-v`; `postgres_data` зберігається.
10. **Як перевірити дані без pgAdmin?** Через `docker compose exec -T db psql -U taskflow -d taskflow -c 'SELECT * FROM tasks;'`.
11. **Що таке `docker build`, `run`, `logs`?** Збірка образу, запуск контейнера, перегляд його логів.
12. **Чи однакова база в `npm start` і Docker?** Ні. Локальний режим — SQLite, Docker Compose — PostgreSQL; автоматичного перенесення даних немає.
