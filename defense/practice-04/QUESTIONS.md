# Можливі питання

1. **Моноліт vs мікросервіси?** Один процес і розгортання проти незалежно розгортуваних сервісів; для невеликого сольного проєкту достатньо модульного моноліту.
2. **Що таке CRUD?** Create, Read, Update, Delete.
3. **Що таке REST?** Стиль API з ресурсами, HTTP-методами та статусами.
4. **Чому PATCH, а не PUT?** PATCH змінює лише передані поля, а PUT зазвичай означає повну заміну ресурсу.
5. **Що таке DTO?** Дані для обміну через API, без бізнес-логіки.
6. **Навіщо OpenAPI?** Машиночитаний контракт маршрутів, схем та відповідей.
7. **Що означає 201?** Ресурс створено.
8. **Чому 204?** Операція успішна, тіло відповіді не потрібне.
9. **Де перевірка даних?** У TasksService, домен додатково контролює інваріанти.
10. **Що таке ADR?** Запис важливого архітектурного рішення разом із причинами й наслідками.
