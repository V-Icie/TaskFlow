# Сценарій захисту №1 через Google Meet

Орієнтир: 3–5 хвилин. Це підказка для живої демонстрації, а не текст, який потрібно читати напам'ять.

## Перед дзвінком

1. Відкрийте папку проєкту у VS Code.
2. У терміналі запустіть `npm start`.
3. У браузері відкрийте http://localhost:3000 та http://localhost:3000/items у другій вкладці.
4. Переконайтеся, що виводяться чотири тестові записи.
5. Підготуйте GitHub головного репозиторію й pull requests учасників, якщо командна частина виконана.

## Жива демонстрація

1. **Тема.** «Ми розробляємо TaskFlow, вебсистему для керування завданнями».
2. **Сервер.** Покажіть термінал із повідомленням про запущений сервер.
3. **Інтерфейс.** Покажіть сторінку, натисніть **Load items**. З'явиться список із бази даних.
4. **API.** Відкрийте `http://localhost:3000/items`, покажіть JSON з `id` і `name`.
5. **Код.** Відкрийте `src/app.js` і покажіть `GET /items`; відкрийте `src/db.js` і покажіть SQL-таблицю та тестові записи.
6. **Git.** Покажіть головний репозиторій та реальні PR/merge, якщо вони є. Якщо немає, чесно повідомте про стан цієї вимоги.
7. **Підсумок.** «Браузер робить HTTP GET, Express звертається до SQLite, отримані записи повертаються як JSON і відображаються на сторінці».

## Запасний варіант

Якщо браузер не відкриває застосунок, перевірте чи запущений `npm start`, чи правильний порт і чи не виведено помилку в терміналі. Якщо сервер зупинився, перезапустіть його. Не демонструйте скриншот як доказ поточної працездатності без відповідного пояснення.

## Докази до збереження (вручну)

- Скрін браузера зі списком після натискання кнопки.
- Скрін JSON відповіді `GET /items`.
- Скрін термінала із запущеним сервером.
- Посилання на реальний головний GitHub-репозиторій та PR, якщо виконано.

Покладіть власні скриншоти у `evidence/`.
