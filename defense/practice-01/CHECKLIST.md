# Контрольний список практичної №1

## Технічні вимоги

- [ ] `npm install` виконано на ПК студента.
- [ ] `npm start` запускає Express без помилок.
- [ ] `http://localhost:3000/items` повертає JSON із бази.
- [ ] SQLite створює таблицю `items (id, name)`.
- [ ] У таблиці є кілька тестових рядків.
- [ ] Кнопка **Load items** показує список на сторінці.
- [ ] `npm test` завершується успішно.

## Командна робота

- [ ] Обрано тему TaskFlow.
- [ ] Створено головний GitHub-репозиторій лідера.
- [ ] Учасники створили форки (якщо є команда).
- [ ] Учасники працювали в окремих гілках.
- [ ] Відкрито реальні pull requests.
- [ ] Виконано review та merge.

## Дистанційна здача

- [ ] README прочитано, команди відомі.
- [ ] Готовий браузер із двома вкладками (сторінка та API).
- [ ] Відкриті `src/app.js` і `src/db.js` у VS Code.
- [ ] Справжні скриншоти збережені в `evidence/`.
- [ ] Студент може пояснити client → backend → database.

Статус: **готова кодова база; локальний запуск Express, Git workflow та демонстрація потребують підтвердження на ПК студента**.
