# Питання й короткі відповіді для захисту

**Що таке frontend?** Код, який виконується в браузері та відображає інтерфейс (HTML, CSS, JavaScript).

**Що таке backend?** Серверний код, який приймає запити, обробляє їх та звертається до бази даних.

**Що робить GET /items?** Читає всі рядки таблиці `items`, сортує за `id` і повертає JSON-масив.

**Чим SQLite відрізняється від PostgreSQL?** SQLite зберігає базу у локальному файлі й не потребує окремого сервера; PostgreSQL працює як окремий сервер СУБД і краще підходить для багатьох одночасних користувачів.

**Що таке endpoint?** Конкретний HTTP-маршрут API разом із методом, наприклад `GET /items`.

**Як клієнт звертається до API?** Через `fetch('/items')`, після чого читає JSON і створює елементи списку.

**Навіщо Git і GitHub?** Git відстежує версії коду, GitHub дозволяє спільно працювати з репозиторіями, переглядати зміни та проводити review.

**Що таке fork?** Власна копія іншого GitHub-репозиторію в акаунті учасника.

**Що таке pull request?** Запит на включення змін із гілки або fork до іншої гілки, зазвичай після review.

**Чому дані не прописані просто в JavaScript?** Вимога практичної: дані повинні надходити з БД через бекенд, а не бути статичним масивом на клієнті.
