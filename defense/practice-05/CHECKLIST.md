# Чекліст для практичної №5

## Перед здачею

- [ ] У каталозі `TaskFlow` виконано `npm install`, потім `npm test`.
- [ ] Усі тести, включно з HTTP integration tests, успішні (2 HTTP-тести запускаються лише за наявності Express).
- [ ] Сервер запущено: `$env:DEMO_FAILURES='1'; npm start`.
- [ ] Відкрито `http://localhost:3000/`.
- [ ] `Load items` працює (практична №1).
- [ ] Create, Complete, Edit через input+Save і Delete через Confirm delete працюють.
- [ ] `GET /health` повертає `{ "status": "ok" }`.
- [ ] Два однакові POST з одним `Idempotency-Key` мають однаковий ID й не створюють дубліката.
- [ ] Кнопка `503 → retry` відображає повтор і успіх.
- [ ] Кнопка `429 → Retry-After` відображає очікування 1000 мс та повтор.
- [ ] Кнопка `Timeout 1с` демонструє скасування запиту приблизно через 1 секунду.
- [ ] Кнопка `3 помилки → degraded` показує банер та блокує CRUD на 8 секунд.
- [ ] Реальні скриншоти або записи логів збережено в `evidence/` (не вигадувати).
- [ ] Оновлений `docs/api/openapi.yaml` перевірено в Swagger Editor (скрин з №4 потребує повторної перевірки після змін).
- [ ] `git status`, commit і push перевірені, в Git не потрапили `data/`, `node_modules/`, `.env`.

## Примітки

Налаштування `DEMO_FAILURES=1` впливає лише на localhost. Воно не вмикається під час звичайного запуску; вимкни його після демонстрації командою `Remove-Item Env:DEMO_FAILURES` або закрий термінал.
